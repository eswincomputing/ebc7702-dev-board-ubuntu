R01A12, 2025-10-30

Changelog:
CR: Dual-die boards automatically adjust frequency based on network model weights.  
CR: Added DSP operators: RGB2HSV, RGB2GRAY, HoughLines, Sobel, Canny, GaussianBlur, Dilate, Erode, DFT
CR: Optimized dual-die phase adjustment tool  
CR: Added configurable esfand for setting target center temperature  
CR: Optimized preboot logo BMP image pixel display  
CR: Added dynamic frequency adjustment for Dec, Enc, and 2D  
CR: Updated gamma fun for Wayland compatibility  
CR: Added USB audio functionality  
CR: VI feature update: DVP2AXI supports RG888; added compatible sensors: IMX415 sensor, OV5647 and OV9281, IMX219; kernel device tree supports overlay  
TR: NPU freezes with a low probability during IPA frequency modulation.
